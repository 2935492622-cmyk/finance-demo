# 测试与验收计划

版本：0.1，状态：用户已于 2026-11-16 确认。这里是验收基线，不是执行报告；第三阶段实际结果另见 docs/qa/，真实 MySQL 成功路径仍待验证。

## 分层与前提

- 环境层：已完成 Python 依赖检查、导入、隔离和临时内存请求冒烟。该结果不能代表记账 API 或 MySQL 测试通过。
- 后端层：Pydantic、Decimal、共享筛选与错误响应由 backend-developer 在 `backend/tests/` 验证。
- 独立 QA：qa-reviewer 在 `tests/` 编写测试、在 `docs/qa/` 保存用例 / 缺陷 / 执行报告，并完成真实 API、浏览器与 SQL 交叉验证。
- MySQL 未部署或前后端未启动时，相应测试标记“受阻 / 未执行”；不得使用 SQLite 或模拟响应作为最终集成验收。

## 测试数据与隔离

本项目只使用 `finance_demo`，不额外创建测试数据库。不清空已有用户数据。执行前记录现有数量和统计，以唯一备注前缀 `qa-<run-id>` 标识测试记录并保存创建 ID；只删除明确由本次测试创建的记录，不用全表 DELETE、TRUNCATE、drop/create 或 `--create-db`。

空集合测试优先使用预先确认不存在的唯一分类筛选，让匹配集合为空；全库空状态仅在确认为干净数据库时验证。SQL 验证由专用应用账号执行 SELECT，报告不包含真实密码、连接串或完整 `.env`。截图中测试数据与用户数据应明确区分。

## 核心测试矩阵

| 编号 | 场景 / 输入 | 预期 |

| DELETE-01 | 删除测试记录，再次删除同一 ID | 首次 204 空体、SQL 不存在、统计更新；第二次 404 |
| ID-01 | 不存在的合法 ID；0、负数、非整数或超范围 ID | 不存在为 404；非法 ID 为 422，统一错误格式 |

| FILTER-03 | 大小写不同的分类、中文和带引号文本 | 依指定排序规则精确匹配，无 SQL 拼接或注入效果 |
| CHART-01 | 多分类支出、仅收入、无匹配 | 分组金额合计等于支出总额；无支出为空态 |
| ERROR-01 | 用错误连接配置启动独立测试后端进程 | health / 数据请求为 503，无 SQL 或凭据泄露；不停止共享 MySQL |
| ERROR-02 | 非预期异常路径（可用受控单元故障注入） | 500 统一格式，写入回滚；与真实集成测试分别记录 |

所有测试先保证输入其他字段有效，避免本应测试 404 的请求先触发请求体 422。测试只能操纵隔离的测试记录。

## 必须执行的页面 + SQL 端到端场景

1. 确认 MySQL 版本、命名卷、表结构与独立应用账号可连接，记录验收前基线。
2. 页面添加收入 `1000.00`、分类工资、日期 `2026-11-15`、带运行标记的备注。
3. 页面添加支出 `125.50`、分类餐饮、同一日期及运行标记。
4. 记录响应 ID，用 SQL 按这两个 ID 查询 amount、type、category、note、transaction_date，确认实际落库。
5. 页面展示这两条记录；无其他数据时三项卡片为 `1000.00`、`125.50`、`874.50`；有用户数据时按基线增量断言。
6. 刷新浏览器，确认列表与卡片不变；重启本项目后端后再次查询，数据仍在。不得为此重启共享 MySQL。
7. P1 完成后在页面编辑一条测试记录、取消一次删除、确认一次删除，并通过 API / SQL 复核。
8. 在页面切换分类、类型和日期组合，再清空筛选；列表、卡片、图表同步。

前端还需检查金额 `12` → `12.00`、`12.3` → `12.30`、超过两位小数提示、重复点击抑制、网络断开保留输入、保存结果不确定提示、保存成功但重查失败提示，以及快速筛选时旧响应不会覆盖新结果。桌面和窄屏均应可操作，错误不能只显示在控制台。

QA 运行真实集成测试前确认后端地址和本地 `.env`，不要把真实密码作为命令参数。浏览器操作优先使用届时可用的本地浏览器工具；如需额外自动化依赖，先由主 Agent 协调其项目内安装和文件所有权，不全局安装。

最终在 `docs/qa/TEST_REPORT.md` 逐项记录环境、时间、命令、实际结果、断言、SQL 证据和截图路径；缺陷记录到 `docs/qa/BUG_REPORT.md`，写明复现、根因、修复人及复测结果。运行截图至少包含桌面记账页和筛选 / 编辑示例，保存到 `screenshots/`，不能以设计稿或伪造数据截图替代。

先前的 TestClient / HTTPX 组合有已记录的弃用提示；正式离线测试现已采用 HTTPX ASGITransport，避免使用该弃用路径，不通过隐藏警告声称适配完成。
